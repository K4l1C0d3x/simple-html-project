# Creamy Garlic Butter Chicken Recipe

A clean, semantic HTML5 webpage showcasing a structured recipe for Creamy Garlic Butter Chicken.

## Overview

This project serves as a clear, accessible example of using fundamental HTML5 elements to present culinary recipes on the web. It includes an introductory overview, a detailed ingredients list, step-by-step cooking instructions, and food photography.

## Features

- **Semantic Document Markup**: Uses native HTML elements (`<h1>`, `<h2>`, `<p>`, `<ul>`, `<ol>`) for clear document structure and screen-reader accessibility.
- **Categorized Lists**:
  - Unordered list (`<ul>`) detailing recipe ingredients and measurements.
  - Ordered list (`<ol>`) specifying sequential preparation and cooking instructions.
- **Media Integration**: Displays an embedded dish photo with descriptive alternative text (`alt`).
- **Minimalist & Lightweight**: Pure HTML with no external dependencies or runtime overhead.

## Getting Started

### Prerequisites

A modern web browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).

### Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/K4l1C0d3x/simple-html-project.git
   cd simple-html-project
   ```

2. **Open the webpage**:
   - Double-click `index.html` to open it in your default web browser, or
   - Right-click `index.html` and choose **Open With** followed by your preferred browser.
